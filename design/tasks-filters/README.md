# Бэклог: фильтры в правой панели (ПК)

До/после ПК-раскладки `/tasks` (ai.cashruflow.ru). Канвас Claude Design.

## Проблема

На десктопе над таблицей идут пять блоков подряд — шапка, вкладки Задачи/Спринты,
строка Проект+Поиск, тулбар из четырёх селектов, панель плиток-виджетов.
По вёрстке `web/public/tasks.html` это 382 px до первой задачи: половина высоты
окна ноутбука 1440×760.

## Предложение

* один ряд шапки: название, вкладки, поиск, `+ Задача`, кнопка «Фильтры N »»;
* под ним — только применённые фильтры чипами (снимаются крестиком) и «Сбросить всё»;
* всё остальное (виды со счётчиками, проект, статус, тип, приоритет, постановщик) —
  в выдвижную правую панель 340 px, открывается кликом по `»`, раздвигает таблицу;
* фильтр применяется сразу, результат виден слева — кнопки «Применить» нет.

145 px до первой задачи вместо 382, 16 строк вместо 10.

## Файлы

* `Before.dc.html` — артборд «ДО»
* `Main.dc.html` — артборд «ПОСЛЕ, панель закрыта»
* `AfterOpen.dc.html` — артборд «ПОСЛЕ, панель открыта»
* `canvas.json` — раскладка канваса и заметки
* `build.mjs` + `_common.css` + `_sidebar.html` — сборка артбордов
* `backlog-filters-panel.html` — собранный канвас

Токены взяты из реального кода: `web/public/ui.css` (`--ui-brand:#00a0ff`,
`--ui-card-border:#262626`), `web/server.js` → `THEME_DEFAULTS` (радиус 8 px,
поля `#1a1a1a`/`#333`, вторичная кнопка `#ccc`/`#333`), `web/public/tasks.html`
(бейджи статусов, цвета приоритетов), `web/public/sidebar.js` (сайдбар 230 px).

Данные в таблице — образец, не выгрузка из бэклога.

## Пересобрать

```
node build.mjs
node <skill>/seed-canvas.mjs --template <skill>/payload.template.html \
  --out backlog-filters-panel.html --title "Бэклог: фильтры в правой панели" \
  --artboard Main.dc.html --artboard Before.dc.html --artboard AfterOpen.dc.html \
  --canvas canvas.json
```
